## Claude Code

- Before a roadmap job, read its entry in `docs/ROADMAP.md` and the files it names; state the job ID
  you are working on.
- Use the venv interpreter for every Python command (see AGENTS.md); the bare `python` will fail.
- Only one node can bind ports 8000/8001; stop a running server before starting another on the same ports.
